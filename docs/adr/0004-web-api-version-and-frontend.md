# ADR-0004 Web API 版本与前端技术栈
日期：2026-09-12
状态：已接受

## 背景

旧 Web 页面由 Flask/Jinja 提供，内联脚本和管理 URL 已被外部使用。一次切换到大型
前端框架会同时改变鉴权、CSRF、移动端布局和部署方式。

## 选项

1. 立即引入 SPA 框架并删除旧 URL。
2. 保留 Jinja，使用原生 ES modules 拆分页面；新接口固定在 `/api/v1`，旧 URL
   通过 308 转发。

## 决策

采用选项 2。共享请求、状态和 DOM 工具位于 Web adapter，页面脚本不再内联；所有
接口声明方法、权限和统一错误 envelope，并返回 `request_id`。

## 代价与风险

需要同时维护旧 URL 一个兼容周期；原生模块缺少框架级组件生态，但能降低运行时依赖
和 Termux 部署风险。

## 迁移和回滚

页面逐个迁移，保留旧模板和 308 路由。新页面或 API 出现问题时关闭对应 manifest
开关并恢复旧路由，不删除旧数据。

## 影响的 feature / 数据 / API

影响 `adapters/web`、所有 `/api/v1` feature blueprint 和管理页面；不改变玩家资产
表结构。
