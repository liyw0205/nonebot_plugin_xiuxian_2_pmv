# ADR-0006 旧命令与旧 URL 兼容周期
日期：2026-09-12
状态：已接受

## 背景

玩家仍依赖历史命令、别名、字段和 Web URL。静默删除会造成不可定位的行为变化。

## 选项

1. 新实现上线即删除旧入口。
2. 保留一个完整发布周期，以 manifest、DeprecationWarning 和命中计数观测，满足
   P7 条件后再移除。

## 决策

采用选项 2。兼容入口只负责解析/投影并转发 application；每次命中写入脱敏计数。
只有连续一个发布周期无命中、历史安装迁移完成、恢复演练通过且旧 URL/import 无
运行日志命中，才允许删除 shim。

`CompatibilityReleaseGate` 将发布起点的命中基线、后续版本号、日志扫描结果和带
SHA-256 manifest 的恢复回执写入数据目录；关闭 gate 是删除 shim 评审的必要前置条件，
不能用测试环境的模拟版本号替代真实发布记录。

## 代价与风险

迁移期代码重复且需要维护旧响应格式；兼容层不得继续新增业务规则。

## 迁移和回滚

新 feature 通过灰度开关切回旧实现；删除前保留备份和 operation ledger，异常时恢复
旧代码和旧 manifest。

## 影响的 feature / 数据 / API

影响 `compatibility/`、旧 `xiuxian_*` 包、命令别名、旧 Web URL 和字段投影；不改变
新 API 的版本路径。
