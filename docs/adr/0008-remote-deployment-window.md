# ADR-0008 远端部署停机窗口
日期：2026-09-12
状态：已接受

## 背景

远端服务可能仍运行旧实例，直接迁移会产生并发写入和无法回滚的数据库状态。

## 选项

1. 在线直接执行迁移并覆盖旧进程。
2. 在受控停机窗口内执行备份、dry-run、隔离旧实例、启动新实例、健康检查、只读
   命令和可回滚写操作，最后恢复旧实例（灰度时）。

## 决策

采用选项 2。`scripts/remote_smoke.sh` 只接受显式项目目录、数据目录、服务停止/启动、
可逆写和回滚 hook，并通过 SSH wrapper 运行；缺少任一危险操作参数时拒绝执行。

## 代价与风险

需要服务管理员提供正确的 systemd/进程管理命令，停机窗口长度取决于备份和迁移耗时。
脚本不会猜测进程名，也不会复制 wrapper 内的凭据。

## 迁移和回滚

备份路径写入 smoke 过程变量；失败 trap 停止新实例并调用回滚 hook。健康检查必须
通过 `/health/ready`，对账必须没有待处理 operation/outbox/dead event。

## 影响的 feature / 数据 / API

影响远端部署、全部数据库备份/迁移和 `/health/ready`；不改变本地开发启动方式。
