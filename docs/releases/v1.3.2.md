# v1.3.2

本版本修复思恋结晶超 int64 余额的精确持久化与回放，涉及传承祈愿、流沙、分解、
管理员调账、虚神界对决、轮回及遗留结晶写入 API，不新增玩法或改变奖励数值。

启动迁移以 `stone_num_exact TEXT` 保存权威余额，保留旧余额作为兼容镜像。旧 INTEGER、
科学计数法整数 TEXT 和绝对值小于 `2**53` 的整数 REAL 可精确迁移。无法恢复原值的
大数 REAL、非整数或无效历史值保留具体拒绝原因和主体，零业务写入，不猜测余额。
一致历史镜像不相加；真正分歧仍拒绝，不能靠覆盖历史记录消除报错。

余额、卡片、统计与永久操作回执同事务提交；重复请求不再次扣费，payload 冲突拒绝，
写入故障完整回滚。旧兑换的背包授予、结晶清零与回执也在同一事务，批量总额从精确
JSON 回执计算。旧镜像单列更新由写入保护拒绝。

定向受影响组 158 项、38 个子场景通过；真实 dispatch 五场景为 2 个成功、3 个具体
拒绝，零 exception/blocked。CI 发现的迁移夹具及旧结果对象兼容问题已修，52 项、
21 个子场景定向复测通过，修正 SHA 完整 CI 5992 项通过。重叠结果不累计，未扩大为
所有参数指令通过的声明。

版本字段：`data/xiuxian/version.txt` 为 `v1.3.2`。正式附件仍为 `project.tar.gz`。
