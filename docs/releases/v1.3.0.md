# v1.3.0

活动集字新增定向换字：在活动背包查看比例与缺字建议，用
`活动换字 源字 目标字 [活动名]` 消耗指定源字获得一张目标字，再通过原有活动兑换
领取词组奖励。随包庆典配置启用 5 换 1；已有活动配置默认不启用，可通过
`synthesis.enabled/cost` 选择开放。换字不增加任务、积分、战令或掉落进度。

启动迁移只新增换字回执表，保留原库存与兑换记录。扣字、入字与回执整事务提交，
重复消息及提交后的中断恢复不重复扣字或造字，失败保留具体原因。超出 SQLite
可精确保存的库存变化会完整回滚。原词组奖励、掉率、保底和兑换限额保持既有规则。

版本字段：`data/xiuxian/version.txt` 为 `v1.3.0`。仅走现有正式 Release 工作流
提供 `project.tar.gz`；没有部署、重启或真实玩家库/QQ 测试。
