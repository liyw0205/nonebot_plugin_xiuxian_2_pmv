修复 v1.3.18 质量门失败所暴露的运行时回归，并补齐饰品分解的事务与重放合同。

- 修复操作账本比较 JSON 审计投影时将 tuple 与 list 视为不同值，导致宠物游历领取、孵化和战斗结算失败。
- 修复竞技场科学计数历史数据的结算判定、赛季总荣誉回执及仙肆大额价格/手续费的精确整数投影。
- 单件与快速分解饰品在石料、饰品状态或永久回执拒写/改写时整笔回滚，保留具体原因；快速分解成功后同消息重放不会分解新到饰品。
- 对齐旧竞技场拒写测试的结果合同，逐原因验证失败步骤与主体；修正数据库清单 SQL 识别和宗门成员调用计数。

v1.3.18 的 tag 保留原指向；其质量门失败后没有生成 Release。本版本不包含本地 goal/status、用户数据或部署变更。
