# v1.3.3

本版本修复货币精确比较与结算一致性问题，覆盖灵石、灵庄存款、活动积分、宗门贡献、
世界积分、历练积分、通天塔积分和竞技场荣誉等已有货币或兑换资产的实际读写入口。
int64 范围内继续使用 SQLite INTEGER，超出范围的新增精确整数使用 ASCII 整数 BLOB
绕过 SQLite affinity，读取、比较、CAS、扣增和流水聚合不再经过 REAL 运算。

仙肆双边购买、活动购买、活动兑换、任务奖励、灵石赠送、灵庄存取、共同奖励、宗门商店、
管理员调账和相关历史消费者均补充了真实业务分支回归。余额重读、扣增、库存、operation/
ledger 回执、回复、并发、重复请求、payload 冲突和事务故障都必须与数据库状态一致。

历史 INTEGER、精确科学计数法 TEXT、安全整数 REAL 和精确 BLOB 可兼容读取；绝对值达到
`2**53` 的 REAL、非整数和无效金额不能恢复精度时，保留字段、reason、subject 并零业务
写入，不能猜测、相加或覆盖坏记录。灵庄历史导入整批回滚；结晶 `stone_num_exact`
authority 与真实镜像分歧拒绝规则保持不变。

本阶段定向真实参数链覆盖 12 条代表场景（7 条成功、5 条具体拒绝），受影响回归和
边界测试已纳入正式 CI。修正后的 develop 精确 SHA CI 通过 6049 项测试及编译、架构、
清单和 whitespace 门禁；未宣称所有参数指令或生产历史数据均已恢复。未部署、未重启、
未读取真实玩家库、未发送 QQ。

版本字段：`data/xiuxian/version.txt` 为 `v1.3.3`。正式附件仍为 `project.tar.gz`。
