# 娱乐功能

娱乐模块入口：

```text
娱乐帮助
小游戏帮助
```

## 链接解析

```text
链接解析 <分享链接>
```

支持平台、代理和排错见 [链接解析文档](media_parser.md)。境外平台仅在需要时启用 `custom_proxy`。

## WebDAV

绑定和删除仅管理员可用；普通用户可浏览目录和获取链接。

| 指令 | 说明 |
|:-----|:-----|
| `webdav帮助` | 查看用法 |
| `webdav绑定 备注#地址#用户名#密码` | 管理员绑定账号 |
| `webdav查看` | 查看绑定列表 |
| `webdav列表 [序号] [路径]` | 浏览目录 |
| `webdav信息 [序号] <路径>` | 文件或目录信息 |
| `webdav链接 [序号] <路径>` | 获取下载地址 |
| `webdav文件 [序号] <路径>` | 获取文件地址 |
| `webdav删除 序号|全部` | 管理员删除绑定 |

凭据保存在本地数据目录，禁止提交到 Git。

## 今日番剧与周表

```text
今日番剧
番剧周表 [页码]
```

当前数据源为 Jikan `seasons/now`，并使用本地缓存。网络失败时会使用缓存或返回明确错误；仅在本机确有网络限制时配置代理。

`番剧盲盒` 是独立的随机番剧功能，不等同于今日放送列表。

## NewAPI

按 QQ 隔离绑定多个 NewAPI 站点账号：

| 指令 | 说明 |
|:-----|:-----|
| `newapi帮助` | 查看格式 |
| `newapi绑定` | Token/Cookie 绑定 |
| `newapi查看` | 查看当前 QQ 的绑定 |
| `newapi签到 [序号]` | 单个、多个或全部签到 |
| `newapi签到历史` | 最近记录 |
| `newapi自动签到 序号` | 切换自动签到 |
| `newapi信息 [序号]` | 查询用户信息 |
| `newapi删除 序号|全部` | 删除绑定 |

绑定和签到历史保存在 `data/xiuxian/` 下的娱乐模块数据目录，不属于源码。
