# 常用玩法说明（玩家 / 服主）

完整指令以群内 **`修仙帮助` / `娱乐帮助` / `修仙手册`** 为准。本文只补充近期行为与易踩坑点。

## 修为奖励与境界压制

各玩法修为奖励统一锚定「本境 → 下境」升级缺口（gap），并按境界压制
`min(0.1×rank_slot÷3, 1)` 缩放：历练事件、爬塔每 10 层、幻境、前尘轮回、
宗门任务一致。因此后期一次事件仍只占升级需求的固定小百分比，升级节奏由
玩法次数与体力约束决定，不会因单事件刷取而崩塌。突破成功另返 1% 缺口
（传承/道侣类由「不超过对方修为 10%」上限承担）。突破失败扣除当前境
修为 10%~20%。

## 修仙签到

- `修仙签到` / `签到` 每天一次，成功后在回复里显示本月签到日历与连续天数。
- 同一天重复发送不会重复发灵石；即使服务器每日重置任务延迟执行，也不会把当天已签
  清掉再让你领一次。
- 日历只记录功能上线后的签到；此前的历史没有日期记录，不显示，也没有补签入口。

## 悬赏令

| 指令（示例） | 说明 |
|:-------------|:-----|
| `悬赏令刷新` | 刷新可选任务（有次数限制） |
| `悬赏令确认刷新` | 确认本次刷新 |
| `悬赏令接取 1/2/3` | 接取列表中第几条 |
| `悬赏令结算` | 时间到后结算 |

注意：

1. **先刷新出列表**再接取；没有 offer 时会提示先刷新。  
2. 同一 openid 若在库里有**重复角色行**，旧逻辑可能误报「状态或刷新次数已变化」；当前版本刷新会兼容重复行。长期仍建议在库里合并脏账号。  
3. 每日次数由定时任务重置（Web「定时任务」里可见「悬赏令次数重置」）。

## 秘境 · 秘藏令

- 普通进入：同一轮秘境不可重复进。  
- **秘藏令**（ticket）：可在已参加过本轮的情况下**额外再进**（仍要求角色当前为空闲等业务条件）。  
- 以群内秘境相关帮助与道具说明为准。

## 探索结算

- 指令：`探索结算`（地图探索结束后）。  
- 若出现「探索结算数据异常」：多为历史脏快照（如 `reward_plan` 被写成字面量 `None`）。当前版本会清空脏数据并按探索状态重算，一般可直接再结或已自动可结。  
- 结算成功后探索状态会清零，无需对同一笔重复结算。

## 双修 / 高境界数值

- 高境界经验值极大时，旧版用 SQL `CAST(exp)` 精确比对可能**假失败**（看起来没加经验）。  
- 当前双修、道侣/师徒相关返修与传功已改为更稳妥的整数比对；若仍异常请看日志并反馈 user_id。  
- 带按钮的失败提示会带上按钮参数，避免界面显示 `None`。

## 称号自动检查

- 成就/称号自动检查依赖玩家数据管理器；旧版缺导入会导致日志 `player_data_manager is not defined`。  
- 已修复后自动检查不再刷该错误；玩家侧一般无感。

## 娱乐房间重启恢复

- 五子棋 / 十点半 / 扫雷的房间在机器人重启后仍然存在，但「超时」计时器不随进程
  保留；现在启动恢复会一次性处理：已经超时的房间直接释放，其余房间按**剩余
  时间**重建计时器（重启不会重置为完整时长）。
- 因此重启后旧房间不会再永久卡住；被释放的房间不再占用你，可以直接重新开局
  （`开始五子棋` / `开始十点半` / `开始扫雷`）。
- 启动期的释放是**静默**的（此时没有可用的群上下文，不发提示）；正常在线期间的
  超时提示文案不变。

## 鬼市订单生命周期

- `鬼市求购` 创建时按「单价 × 数量」冻结鬼市账户灵石；订单在**次日 8 点**自动
  取消，未成交部分的冻结灵石自动退回鬼市账户，可用 `鬼市信息` 查看余额。
  手动 `鬼市取消求购 <订单ID>` 立即退回未成交部分。
- `鬼市摆摊` 创建后会**立刻撮合**已有求购订单（同物品、求购价不低于摆摊价、
  不能与自己成交，先到先得），成交结果直接出现在摆摊回执里。
- 成交按**摆摊价**结算：求购出价高于摆摊价时，差价同时退回买家鬼市账户，
  买家最终支出等于成交数量 × 成交价。
- 次日 8 点仍未售出的摆摊物品退回背包（背包已满时保留摊位，腾出空间后自动
  在下次清理时退回）。
- `鬼市信息` 的每笔订单都会显示到期时刻与剩余时长；**历史订单**（早于本功能
  创建、没有创建时间记录）不显示到期时刻，也不会被自动取消，需要手动取消。

## 通天塔

- `通天塔信息` 现在显示下一里程碑、还差几层、该层首通积分/灵石/修为预览，以及
  本周兑换进度与已兑完商品数。
- 每周一 0 点重置层数与商店限购；没有有效限购商品时仍显示里程碑。

## 组队邀请

- 不在队伍中时发送 `查看队伍`，若有未过期邀请会显示【待处理组队邀请】：队伍、邀请人、
  发起群和剩余时间，并提示回复 `同意组队` 或 `拒绝组队`。
- 没有邀请或邀请已过期时仍显示“你不在任何队伍中”和创建队伍提示；邀请到期后不会显示。

## 竞技场荣誉

- `我的荣誉` 在“明日预计奖励”之后显示【最近荣誉结算】：最近最多 5 次每日自动结算的
  日期、基础荣誉、排名奖励、本次总计与结算后荣誉。
- 无记录时提示“暂无荣誉结算记录；每日 0 点结算后在此显示”；旧记录缺明细时只显示
  本次总计与结算后荣誉。
- 每日荣誉仍由系统自动发放，不需要也不会手动领取；该段只用于核对到账。

## 魔修入侵

- `魔修入侵` 状态页会显示【你的战功】：本期累计出手与真实伤害、当前境界波次的名次与
  本波伤害占比。即使不在前五名榜单里，也能看到自己的名次。
- 奖励状态会标明“本期已领取”“可领取”“本期结束后按贡献结算”或“尚未参与”；
  可领取时按提示发送 `领取魔修奖励`。

## 仙肆交易

- `我的仙肆` 查看自己当前上架的物品；`我的仙肆 记录`（也可用 `成交`/`历史`）查看最近 5 笔
  仙肆成交。
- 记录会区分“卖出/买入”，显示物品、数量、成交总额、对手方与时间，并给出这 5 笔的
  卖出收入与买入支出汇总。系统商品显示卖家为“系统”。
- 仙肆手续费在上架时收取，成交页只显示成交总额，不重复扣手续费；成交记录来自
  已持久化的成交账本，物品售罄后仍可回查。

## 拍卖结算与待领取

- 拍卖结算会把拍品直接放进中标者背包，把流拍拍品退回卖家背包；不会再因为
  「你已经有一件同名物品」而丢失或卡住整场。
- 如果你的背包里该物品已达上限（默认 1000 件），结算不会失败，也不会吞掉物品：
  它会进入**拍卖待领取**。`我的拍卖` 会同时列出等待区物品和待领取物品。
- 领取：`我的拍卖 领取` 领取全部可领取物品，`我的拍卖 领取 拍卖ID` 只领指定一件。
  背包仍满时该件会留在待领取，腾出空间后再领即可。
- 待领取物品永久保留在你名下，不会过期消失。
- `我的拍卖` 还会列出 `【我的竞价】`：你参与的拍品、你的出价、当前最高价，以及
  「领先」或「已被超价」。被超价时你的灵石会自动退回，并收到一条
  `[拍卖被超价] … 原出价 N 灵石已退回` 的日志，不需要自己盯余额。
- `【本场拍品】` 列出你正在拍卖中的物品：当前价、出价次数/人数与剩余时间。开拍后拍品
  从等待区进入本场，仍可在这里看到；拍卖进行中不能下架。
- `【最近拍卖记录】` 保留最近 5 条成交/流拍：卖出行显示成交价、手续费、实收与买家；
  拍得行显示成交价与卖家；背包已满而转入待领取的物品会标注「物品在拍卖待领取」。

## 定时任务（服主）

日常重置、备份、鬼市、傀儡收取、世界事件等见 Web 面板 **定时任务** 页，或 [web_panel.md](web_panel.md)。  
玩家侧只需知道：次数类玩法会在配置的时间点重置。
